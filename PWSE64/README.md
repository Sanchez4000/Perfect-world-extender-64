# PWSE64 — Perfect World Server Extender 64

Загрузчик плагинов для игрового сервера Perfect World (бинарник `gs`, ELF64 PIE x86-64).
Подключается через `LD_PRELOAD`, позволяет добавлять серверные фичи отдельными плагинами,
не изменяя сам бинарник сервера.

## Как работает

1. Обёртка `gs` задаёт `LD_PRELOAD = pwse_loader.so` и запускает настоящее ядро сервера (`gs.real`).
2. Загрузчик при старте читает библиотеку адресов (`plugins/_addresses.ini`), сканирует
   `plugins/` и для каждого `.so` вызывает точку входа `PwsePluginLoad`.
3. Плагин ставит хуки на функции движка по именам из библиотеки адресов и/или вызывает их напрямую.

Бинарник сервера не модифицируется. Адреса функций заданы внешним файлом и специфичны для
конкретной сборки `gs`.

## Структура

- `Source/` — исходники загрузчика (→ `pwse_loader.so`). `vendor/subhook` — библиотека хуков.
- `SDK/` — шаблон проекта плагина.
- `Release/` — готовые сборки по версиям (`Release/README.md`).
- `Addresses/<версия игры>/_addresses.ini` — библиотека адресов.

## Требования

Docker Desktop. Сборка выполняется в контейнере `pwse64-toolchain` (Ubuntu 22.04, gcc),
целевая платформа — Linux x86-64. Образ собирается при первом запуске `build.bat` из
`toolchain/Dockerfile`. Компилятор на хосте не нужен.

## Сборка загрузчика

`Source/build.bat` → `Source/build/pwse_loader.so`.

## Разработка плагина

Скопировать `SDK`, задать имя копии, реализовать `src/plugin.c`, собрать `build.bat` →
`build/<имя>.so`. Подробнее — `SDK/README.md`.

## Установка на сервер

Каталог `gamed/` (рядом с `gs`):

1. При первой установке переименовать исполняемый файл сервера `gs` в `gs.real`.
2. Скопировать в `gamed/` содержимое каталога версии из `Release/<версия>/`: обёртку `gs`
   (исполняемый файл, переводы строк LF), `pwse_loader.so` и каталог `plugins/`.
3. Скопировать `.so` плагинов в `gamed/plugins/`.
4. Перезапустить карты.

Загрузчик пишет в стандартный вывод процесса строки с префиксом `[pwse]`.

## Обновление

- Загрузчик: заменить `pwse_loader.so`.
- Плагин: заменить соответствующий `.so` в `plugins/`.
- Адреса: дополнить `plugins/_addresses.ini`.

Файлы заменяются при остановленной карте.

## Откат

Переименовать `gs.real` обратно в `gs`, удалить `pwse_loader.so` и каталог `plugins/`.
Бинарник сервера при установке не изменяется.

## Библиотека адресов

Файл `plugins/_addresses.ini`. Формат строки: `<имя> = 0xАДРЕС ; сигнатура`.
Строки, начинающиеся с `#` или `;`, игнорируются.

- Адрес — виртуальный адрес из ELF, как в выводе `nm`. `gs` собран как PIE: загрузчик прибавляет к адресу базу загрузки.
- Имя — имя функции без списка аргументов, как в `nm -C`. Строка с `=` в имени не читается.
- Файл читается один раз при старте `gs`. Лимиты: 1024 записи, имя до 191 символа, строка до 1023 символов.
- Адреса действительны для `gs`, из которого они взяты. Размер и SHA-256 бинарника указаны в заголовке файла.
- Новый адрес добавляется в `Addresses/<версия игры>/_addresses.ini`; копия файла лежит в `plugins/` каждой версии релиза и на сервере.

Адрес функции: `nm -C --defined-only gamed/gs.real | grep "<имя>("`.

## API плагина

Структура `PwseApi` (`SDK/include/pwse.h`), точка входа `int32 PwsePluginLoad(const PwseApi* api)`.
Возврат `0` — плагин загружен, иначе загрузчик выгружает плагин.

| Поле | Назначение |
|---|---|
| `abi_version` | Версия ABI, `PWSE_ABI`. |
| `Log(message)` | Строка в лог процесса с префиксом `[pwse]`. |
| `Resolve(name)` | Абсолютный адрес функции. `0` — имени нет в библиотеке адресов. |
| `Hook(name, detour, original)` | Детур на функцию. В `original` записывается указатель на оригинал. |

Коды `Hook`: `0` — успех, `-1` — имени нет в библиотеке адресов, `-2` — хук не создан,
`-3` — хук не установлен, `-4` — трамплин на оригинал не создан.

## Ограничения хуков

Переход в начало функции занимает 14 байт. Хук не устанавливается (`-4`, функция
остаётся без изменений), если:

- функция короче 14 байт;
- в первых 14 байтах есть инструкция, которой нет в таблице дизассемблера `subhook`
  (в том числе `endbr64`);
- в первых 14 байтах есть инструкция с RIP-относительным операндом.

Функцию, на которую хук поставить нельзя, можно вызывать через `Resolve`.
