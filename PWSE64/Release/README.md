# PWSE64 Release

Готовые к установке сборки загрузчика PWSE64. Каждая версия размещается в отдельном каталоге.
Установка, обновление и откат — `../README.md`.

## Версионирование

Формат: `МАЖОР.МИНОР.ПАТЧ` (semver).

- ПАТЧ — исправление или микроулучшение (`1.0.0 → 1.0.1`).
- МИНОР — новая функциональность без несовместимых изменений (`1.0.1 → 1.1.0`).
- МАЖОР — несовместимое или крупное изменение (`1.x → 2.0.0`).

## Состав версии

```
<версия>/
  gs                Обёртка-стартер; задаёт LD_PRELOAD = pwse_loader.so.
  pwse_loader.so    Загрузчик плагинов.
  plugins/
    _addresses.ini  Библиотека адресов.
```

Ядро сервера (`gs.real`) и плагины в состав версии не входят.

## Сборка артефактов

- `pwse_loader.so`: `../Source/build.bat` (вывод в `../Source/build/`).
- Плагины: копия `../SDK` и её `build.bat` (вывод в `build/<имя>.so`).
