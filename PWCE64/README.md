# PWCE64 — Perfect World Client Extender 64

Загрузчик плагинов для клиента Perfect World (`element/x64/elementclient_64.exe`, PE32+ x86-64,
без символов). Позволяет менять поведение клиента отдельными плагинами, не изменяя сам `.exe`.

## Как работает

1. Загрузчик — DLL с именем `FTDriver_64.dll`. Она занимает место оригинальной библиотеки
   шрифтов, оригинал переименован в `FTDriver_64_real.dll`. Клиент импортирует из неё одну
   функцию, `?CreateFTManager@@YAPEAVIFTManager@@HHH@Z`; экспорт загрузчика перенаправлен в
   `FTDriver_64_real.dll`.
2. При загрузке DLL (`DllMain`, до запуска клиента) загрузчик открывает `pwce.log`, читает
   библиотеку адресов `plugins\_addresses.ini`, загружает каждый `plugins\*.dll` и для него
   вызывает точку входа `PwcePluginLoad`.
3. Плагин ставит хуки на функции клиента по именам из библиотеки адресов и/или вызывает
   их напрямую.

Каталог `plugins\` и файл `pwce.log` находятся рядом с `FTDriver_64.dll`. `pwce.log`
перезаписывается при каждом запуске, строки имеют префикс `[pwce]`.

## Структура

- `Source/` — исходники загрузчика (→ `FTDriver_64.dll`). `vendor/subhook` — библиотека хуков.
- `SDK/` — шаблон проекта плагина.
- `Release/` — готовые сборки по версиям (`Release/README.md`).
- `Addresses/<версия игры>/_addresses.ini` — библиотека адресов.

## Требования

mingw-w64 x86-64 в `PATH` (`gcc`). Сборка выполняется на хосте под Windows.

## Сборка загрузчика

`Source/build.bat` → `Source/build/FTDriver_64.dll`.

## Разработка плагина

Скопировать `SDK`, задать имя копии, реализовать `src/plugin.c`, собрать `build.bat` →
`build/<имя>.dll`. Подробнее — `SDK/README.md`.

## Установка в клиент

Каталог `element/x64`:

1. При первой установке переименовать `FTDriver_64.dll` в `FTDriver_64_real.dll`.
2. Скопировать в `x64/` содержимое каталога версии из `Release/<версия>/`: `FTDriver_64.dll` и каталог `plugins/`.
3. Скопировать `.dll` плагинов в `x64/plugins/`.
4. Запустить клиент. Загрузчик пишет `x64/pwce.log`.

## Обновление

- Загрузчик: заменить `FTDriver_64.dll`.
- Плагин: заменить соответствующий `.dll` в `plugins/`.
- Адреса: дополнить `plugins/_addresses.ini`.

Файлы заменяются при закрытом клиенте.

## Откат

Удалить `FTDriver_64.dll` и каталог `plugins/`, переименовать `FTDriver_64_real.dll` обратно
в `FTDriver_64.dll`. `.exe` клиента при установке не изменяется.

## Библиотека адресов

Файл `plugins\_addresses.ini`. Формат строки: `<имя> = 0xАДРЕС ; сигнатура`.
Строки, начинающиеся с `#` или `;`, игнорируются.

- Адрес — виртуальный адрес при базе образа `0x140000000`, как в выводе `objdump`. Загрузчик пересчитывает его на фактическую базу модуля.
- Имя — произвольная строка, присваивается вручную. Строка с `=` в имени не читается.
- Файл читается один раз при старте клиента. Лимиты: 1024 записи, имя до 191 символа, строка до 1023 символов.
- Адреса действительны для `elementclient_64.exe`, из которого они взяты. Размер и SHA-256 бинарника указаны в заголовке файла.
- Новый адрес добавляется в `Addresses/<версия игры>/_addresses.ini`; копия файла лежит в `plugins/` каждой версии релиза и в клиенте.

Адрес функции: `objdump -d -M intel -j .text elementclient_64.exe`. Класс по таблице виртуальных
функций определяется через RTTI (`.?AV…@@`): `TypeDescriptor` → `CompleteObjectLocator`
(сигнатура 1, `TypeDescriptor` по смещению +12) → указатель перед vtable.

## API плагина

Структура `PwceApi` (`SDK/include/pwce.h`), точка входа `PWCE_EXPORT int32 PwcePluginLoad(const PwceApi* api)`.
Возврат `0` — плагин загружен, иначе загрузчик выгружает плагин.

| Поле | Назначение |
|---|---|
| `abi_version` | Версия ABI, `PWCE_ABI`. |
| `Log(message)` | Строка в `pwce.log` с префиксом `[pwce]`. |
| `Resolve(name)` | Абсолютный адрес функции. `0` — имени нет в библиотеке адресов. |
| `Hook(name, detour, original)` | Детур на функцию. В `original` записывается указатель на оригинал; `NULL` — оригинал не нужен. |

Коды `Hook`: `0` — успех, `-1` — имени нет в библиотеке адресов, `-2` — хук не создан,
`-3` — хук не установлен, `-4` — трамплин на оригинал не создан.

Соглашение вызова функций клиента — Microsoft x64.

## Ограничения

`PwcePluginLoad` выполняется внутри `DllMain` под блокировкой загрузчика Windows, до запуска
клиента. Плагин ставит хуки и не ждёт другие потоки.

Переход в начало функции занимает 14 байт. Хук не устанавливается (`-4`, функция
остаётся без изменений), если:

- функция короче 14 байт;
- в первых 14 байтах есть инструкция, которой нет в таблице дизассемблера `subhook`;
- в первых 14 байтах есть инструкция с RIP-относительным операндом.

Функцию, на которую хук поставить нельзя, можно вызывать через `Resolve`.
