# PWCE64 Release

Готовые к установке сборки загрузчика PWCE64. Каждая версия размещается в отдельном каталоге.
Установка, обновление и откат — `../README.md`.

## Версионирование

Формат: `МАЖОР.МИНОР.ПАТЧ` (semver).

- ПАТЧ — исправление или микроулучшение (`1.0.0 → 1.0.1`).
- МИНОР — новая функциональность без несовместимых изменений (`1.0.1 → 1.1.0`).
- МАЖОР — несовместимое или крупное изменение (`1.x → 2.0.0`).

## Состав версии

```
<версия>/
  FTDriver_64.dll   Загрузчик плагинов.
  plugins/
    _addresses.ini  Библиотека адресов.
```

Оригинальная `FTDriver_64.dll` и плагины в состав версии не входят.

## Сборка артефактов

- `FTDriver_64.dll`: `../Source/build.bat` (вывод в `../Source/build/`).
- Плагины: копия `../SDK` и её `build.bat` (вывод в `build/<имя>.dll`).
